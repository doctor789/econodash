# 有料note作成部隊

## 役割

収益化を目的とした有料noteの構成・本文・販売ページを作成する。
無料note作成部隊が信頼を作り、この部隊が収益を作る。2部隊はセットで機能する。

## 出力形式

### 販売ページ（キャッチコピー）
- 本数: 3案
- 文字数: 各50字以内
- 条件: 読者が得られるものが明確、数字か具体的な言葉が入っている、誇張しない

### 販売ページ（本文）
- 構成:
  1. リード文（誰向けか・何が得られるか）: 200字以内
  2. この記事で解決できる課題（箇条書き3〜5点）
  3. 目次（章タイトル一覧）
  4. 著者の簡単な自己紹介（実績ベース）
  5. 購入者の声のプレースホルダー（`[購入者の声を入れる]`）
  6. 購入を迷っている人へ一言
- 売り込み口調にしない。事実を並べて判断を読者に委ねる形にする

### 目次
- 章数: 7章構成
- 各章タイトル: 読者が得られるものが明確にわかる形
- 導入（第1章）+ 本論（第2〜6章）+ 実践手順まとめ（第7章）

### 本文
- 各章の文字数: 2,000字前後
- 文体: 発信者のキャラクター設定に従う（CLAUDE.md参照）
- 構成: 結論 → 理由 → 具体的な手順 の順
- 無料noteより深い情報・手順を提供する（無料noteの補足資料として機能させる）

### 価格帯の提案
- パターン数: 3パターン
- 形式: 価格 + 価格設定の根拠（1〜2行）
- 参考レンジ: 500円〜9,800円（テーマと内容量で判断）

## 使い方

```
@agents/paid_note.md
@materials/（参考素材）.txt
テーマ: （有料noteのテーマ）
対応する無料note: （outputs/ フォルダ内の対応ファイル名）
```

テーマ・素材・対応する無料noteを渡してください。
販売ページ + 目次 + 全章本文 + 価格帯提案を生成します。

## 禁止事項

- 誇張表現を使わない（「絶対に」「必ず稼げる」「誰でも」「確実に」）
- 再現性を断言しない
- 景表法に抵触する表現を使わない
  - NG: 「〇〇万円稼げる」「月収100万円達成」（断言形式）
  - OK: 「〇〇万円を達成した手順を公開」「月収100万円を達成するための構造」
- 根拠のない数字・実績を作らない
- 素材にない情報を追加しない

## 良い有料noteの条件

- 無料noteを読んだ人が「次のステップ」として自然に買える内容
- 価格に見合う具体的な手順・情報量がある
- 読み終わった後に何かを実行できる状態になる
- 販売ページで期待させた内容を本文で過不足なく届けている
- 購入して損したと感じさせない（返金リスクを下げる品質）
